# 화면 가림(마스킹)

실행 중 화면과 스크린샷에서 개인정보를 가리는 방법과, 가리지 못하는 것을 정리했어요. 결정의 근거는 [stage7-contract.md](stage7-contract.md) 5절에 있어요.

## 무엇을 가리나요

- **사이트 셀렉터**: 설정 → 사이트·환경에서 사이트마다 "화면 가림"에 CSS 셀렉터를 한 줄에 하나씩 적어요. 저장할 때 문법을 검사하고, 잘못된 항목이 있으면 몇 번째 항목인지 알려 주고 저장하지 않아요.
- **자동 감지**: 이메일, 전화번호(국내·국제), 카드번호, 주민등록번호 형식의 글자. 8자리 이하 숫자열(가격·날짜 등)은 가리지 않아요.
- **스크린샷 스텝의 `mask`**: 그 스크린샷에서만 덮을 영역이에요. 가격·시각처럼 매번 바뀌는 영역을 가려 두면 시각 회귀 비교에서도 사실상 빠져요.
- **비밀번호·카드 입력칸**과 비밀 값을 넣은 입력칸은 항상 가려요.

화면에서는 대상 요소를 블러로 흐리게 하고 입력창 글자는 점으로 보여요. 페이지의 실제 글자·입력값은 바꾸지 않으니 텍스트 검증은 그대로 동작해요. 스크린샷은 찍는 순간 가림 영역을 단색 상자로 덮어요. 열린 shadow DOM, 같은 출처 iframe, 팝업·새 탭에도 적용돼요.

가림을 적용하지 못하면(셀렉터 오류, 시간 초과 등) 스크린샷을 찍지 않아요. 스크린샷 스텝은 실패로 끝나고, 실패 화면 캡처는 건너뛰어요.

## 시나리오에서 끄기

시나리오 편집기의 "화면 가림" 스위치를 끄면 사이트 셀렉터와 자동 감지만 꺼져요. 스텝 `mask`, 비밀번호·카드 입력칸, 비밀 값 가림은 그대로 유지돼요. 가림이 켜진 실행에서는 trace를 만들지 않아요(trace 안의 DOM 사본은 가릴 수 없어요).

## 가리지 못하는 것

- **영상**에는 화면의 블러·점 표시만 담겨요. 단색 상자와 스텝 `mask`는 영상에 반영되지 않아요.
- 블러는 개인정보 제거를 보장하지 않아요. 첫 화면이 그려지기 전이나 자동 감지가 도는 짧은 사이(최대 약 0.3초)에 몇 프레임 보일 수 있어요. **개인정보가 나올 수 있는 시나리오는 영상을 꺼 주세요.**
- 캔버스·이미지 속 글자, 닫힌 shadow DOM, 다른 출처 iframe, 형식이 정해지지 않은 개인정보(이름·주소 등)는 가리지 못해요. 이런 영역은 사이트 셀렉터나 스텝 `mask`로 직접 지정해 주세요.
