# AI

defE2End는 내 PC에 설치한 AI 코딩 CLI와 함께 동작해요. **서버는 AI 모델을 부르지 않아요.** 요청은 내 PC의 CLI에서 그 CLI의 모델 제공자로, 내 계정으로 나가요.

## 지원하는 CLI

| CLI | 최소 버전 | 상한 |
|---|---|---|
| Claude Code(`claude`) | 2.1.300 | 없음 |
| Codex CLI(`codex`) | 0.162.1 | 없음 |

더 오래된 버전은 이유를 보여 주고 거부해요. 버전 번호를 믿는 대신 매 실행에서 제한을 확인하기 때문에(아래 참고) 상한은 두지 않아요.

defE2End에서 쓰기 전에 CLI를 설치하고 터미널에서 로그인하세요(`claude login`, `codex login`). 로그인이 만료되면 앱이 다시 로그인하라고 알려 줘요.

## MCP 서버

데스크톱 앱에는 로컬 stdio MCP 서버 `defe2end-mcp`가 들어 있어요. 네트워크 포트는 없고, Claude Code와 Codex가 직접 실행해요.

등록하려면 앱 설정의 **AI 연결**을 여세요. 앱이 `claude mcp add --scope user defe2end …`와 `codex mcp add defe2end …`를 대신 실행하고, 기존 `defe2end` 등록이 있으면 바꿔요.

- `defe2end-mcp`는 서버 자격 증명을 갖지 않아요. 같은 OS 사용자만 열 수 있는 로컬 소켓으로 실행 중인 데스크톱 앱과 이야기하고, 앱이 내 권한으로 서버를 불러요. **앱이 꺼져 있거나 로그아웃 상태면 모든 도구가 `desktop-not-running`을 돌려줘요.**
- 도구로 시나리오를 조회·읽기·만들기·실행하고, 결과를 읽고, 사이드 브라우저를 조작할 수 있어요. 파괴적인 작업(실행 취소, 전체 중지, 스케줄 삭제)은 도구로 제공하지 않아요. 웹 화면이나 앱에서 하세요.
- 보기 전용 사용자는 MCP에서도 보기 전용이에요.

## 앱 안 채팅과 실패 진단

앱이 CLI를 대신 실행해 채팅 패널에서 쓰거나 실패한 실행을 설명하게 할 수 있어요. 이때 AI는 **defE2End 도구만** 쓸 수 있어요.

- Claude Code는 내장 도구 없이, `defe2end` MCP 서버 하나만 쓰고, 사용자·프로젝트 설정과 훅·플러그인을 무시한 채 실행돼요.
- Codex는 따로 만든 홈 폴더에서 `defe2end` MCP 서버 하나, 읽기 전용 샌드박스, 내장 도구를 끈 상태로 실행돼요.
- 앱은 실행 전과 실행 중에 CLI가 실제로 불러온 것을 확인해요. 다른 것이 보이면 CLI를 멈추고, 앱을 다시 켤 때까지 그 CLI로 하는 채팅을 거부해요.

한계:

- Codex는 실행 중에 확인하기 때문에, 앱이 멈추기 전에 금지된 첫 호출이 이미 실행됐을 수 있어요.
- 시험하는 페이지 내용이 모델에 문맥으로 전달돼요. 페이지 글은 지시가 아니라 데이터라고 프롬프트에 적지만, 보안 경계는 아니에요. 모델 제공자에게 보낼 수 없는 데이터가 있는 페이지에는 채팅을 쓰지 마세요.
- 채팅 기록은 메모리에만 있고 앱을 끝내면 사라져요.
- 메시지당 이미지는 4장까지, 장당 6MB까지예요.
