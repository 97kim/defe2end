# 보안과 한계

설치 하나는 조직 하나를 위한 것이에요. defE2End는 같은 설치를 쓰는 사람끼리 서로 공격하지 않는다고 보고, 서로 다른 조직을 한 서버에서 격리하지 않아요.

## 비밀 값과 암호화 키

- 비밀 변수는 `DEFE2END_ENCRYPTION_KEY`로 AES-256-GCM 암호화해요. worker가 실행 직전에 복호화해요.
- 키는 DB에도 백업에도 들어가지 않아요. 키를 잃으면 비밀 값을 되살릴 수 없으니 다시 입력해야 해요.
- web 서버는 시작할 때 키를 DB와 대조하고, 다른 키로는 시작하지 않아요.
- 봇 토큰은 해시로 저장하고, 만들 때 한 번만 보여 줘요.

## 화면 가림

화면 가림은 화면과 스크린샷의 개인정보를 가리지만 빈틈이 있어요. 영상, 가림이 적용되기 전 첫 프레임, 캔버스·이미지 속 글자, 닫힌 shadow DOM, 다른 출처 iframe, 이름·주소처럼 형식이 정해지지 않은 정보는 가리지 못해요. 개인정보가 있는 페이지를 영상으로 남기기 전에 [화면 가림](../../masking.md)을 읽어 주세요.

## 시나리오가 닿는 네트워크

worker는 시나리오가 가리키는 주소라면 내부망 주소도 열어요. 시나리오가 사설·루프백·링크 로컬 주소에 닿으면 안 된다면 `BLOCK_PRIVATE_NETWORKS=true`로 정하세요. Chromium 샌드박스는 기본으로 켜져 있어요(`CHROMIUM_SANDBOX`).

## 데스크톱 앱과 로컬 MCP

- 앱과 `defe2end-mcp`는 로컬 소켓으로 이야기해요. macOS에서는 앱 데이터 폴더 안의 유닉스 소켓(폴더 `0700`, 소켓 `0600`), Windows에서는 현재 사용자 SID로 제한한 named pipe예요. 소켓용 세션 토큰은 OS 보안 저장소(키체인, DPAPI)에 보관해요.
- **같은 OS 사용자로 도는 프로세스는 믿어요.** 내 계정으로 실행한 프로그램은 브라우저 데이터를 읽을 수 있는 것처럼 소켓을 열고 토큰을 읽을 수 있어요. defE2End는 내 계정의 악성 코드를 막지 않아요.
- **Windows 파이프 권한:** 접근 제어는 CI에서 시험하지만, 이번 릴리스에서 깨끗한 Windows PC로 사람이 직접 확인하지는 않았어요.
- 앱은 코드 서명이 없어요. 모든 설치 파일을 검증하세요(체크섬과 출처 증명, [desktop-app.md](desktop-app.md#파일-검증)).

## AI

모델 요청은 내 PC에서 CLI의 제공자로 나가요. 앱 안 채팅이 할 수 있는 것과 없는 것은 [ai.md](ai.md)를 보세요.

## 운영하는 분의 몫

TLS, 리버스 프록시, 방화벽 규칙, DB 운영, OS 패치, 백업, 모니터링은 운영하는 분의 몫이에요. `web`은 HTTPS 뒤에 두고, Postgres를 compose 네트워크 밖으로 열지 마세요.

## 취약점 신고

보안 문제는 공개 이슈가 아니라 저장소의 GitHub "Report a vulnerability"로 비공개 신고해 주세요.
